# Trip checklists

- Save the checklist next to the trip's note, as `checklist.md` in the same folder.
- Start the file with `# Trip checklist`.
- One checkbox per document, booking and errand, each as `- [ ] item`.
- Include a `- [ ] Check passport expiry` item even if the trip note does not mention it.
